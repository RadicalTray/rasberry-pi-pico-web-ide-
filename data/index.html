Global Functions & Constants
print(...)
Outputs values to the Web Terminal for debugging. Accepts multiple arguments of any type.
... any - Values to print
digitalWrite(pin, state)
Sets the state of a GPIO pin to HIGH or LOW. Useful for controlling onboard or external LEDs.
pin number - GPIO pin number (e.g. 0-29) state number - Pin state (HIGH or LOW)
analogWrite(pin, val)
Sends a PWM signal (0-255) to a GPIO pin. Useful for fading LEDs.
pin number - GPIO pin number (e.g. 0-29) val number - PWM value (0 to 255)
digitalRead(pin)
Reads the digital state of a GPIO pin (returns HIGH/1 or LOW/0).
pin number - GPIO pin number
analogRead(pin)
Reads the analog voltage value on an ADC pin (returns 0-1023).
pin number - ADC pin number (e.g. 26-28)
pinMode(pin, mode)
Configures the input/output mode of a GPIO pin.
pin number - GPIO pin number mode number - Mode (INPUT, OUTPUT, INPUT_PULLUP, INPUT_PULLDOWN)
delay(ms)
Pauses the execution of the script for a specified duration of milliseconds.
ms number - Delay duration in milliseconds
